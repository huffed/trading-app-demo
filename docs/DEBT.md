# DEBT — the ranked technical-debt register

Written 2026-10-28 on `tooling/dev-setup` (off `dev @ 3ee22e2`). Everything here was **measured**, not guessed; the command or script is named per row and the raw outputs live in the session scratchpad (`metrics/`). Behaviour was not changed: this file is the plan. Findings from the separate audit on `review/skeptical-audit-2026-10` are cited as `audit A#/F#` rather than re-derived.

How to read the register (§2): **Cost** = how much the item slows or endangers development now. **Fix-now?** = can be removed with zero behaviour change (formatting, dead files, duplicate helpers, docs, config) → Phase B; everything else is tagged **wait: Phase E** (and the audit verdict). Every suppression and every "temporary" thing in the code must point at a row here; rows get an owner and a date when they are scheduled.
